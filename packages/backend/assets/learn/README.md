# Learn bundle

`jaffle-dbt.json` is generated by `pnpm build:learn-bundle` (also by
`pnpm build:playground-bundle`) from `examples/full-jaffle-shop-demo/dbt`.
Do not hand-edit it; regenerate it instead.

Shape: `{ version: 1, files: [{ path, content }] }`, `path` values sorted
POSIX paths. Model materialisations are rewritten to `view`. `dbt_project.yml`
keeps `profile: jaffle_shop`, so any generated `profiles.yml` must use that
same top-level key.

Seeds are header-only: the data lives in the embedded `jaffle_shop.duckdb`
database. Never run `dbt seed` against a workspace built from this bundle,
and keep that database read-only.

`analysis-paths`/`test-paths` in `dbt_project.yml` name directories not
included in the bundle; dbt 1.12 tolerates that.

Consumers (Learn sandbox, CS-280) materialise `files` to a temp dir and run
`dbt parse` / `lightdash compile|deploy` there.

`SHA256SUMS` is checked by `pnpm test:playground-content`.
